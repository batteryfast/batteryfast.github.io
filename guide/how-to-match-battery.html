How to match a replacement vacuum battery

A repeatable five-field check prevents most wrong-battery orders. Use it before you compare prices or read reviews.

A note on wording: Batteryfast is an independent compatibility guidance publisher, not the original equipment manufacturer. Brand and model names below identify the machine platform only.

Reviewed 2026-11-25 by the Batteryfast compatibility desk · Specifications must be confirmed on your own battery label.

Check the label before you orderTreat the voltage, capacity (Ah/Wh), part number and connector printed on your original pack as the source of truth. A similar-looking shell is not proof of fit.

The five fields that decide fit

1. Model
Exact machine name and variant, including suffixes
2. SV or machine code
Dyson plate code; a cross-check, not a battery part number
3. Battery part number
The code printed on the original pack
4. Voltage and capacity
Printed V and Ah/Wh; use Wh for comparisons
5. Connector and shell
Plug shape, pin count, screw or click fitting
Our specification policyWe describe platforms and report commonly cited examples. We do not present a figure as universal unless it is printed on the pack or published by the manufacturer.

Dyson versus Roomba identification

Dyson owners should record the SV code from the machine plate and the part number from the pack. Roomba owners should flip the robot for the model sticker and record the ABL or numeric part code from the pack. For robots, Combo status is an extra required field.

Open the Dyson chart or the Roomba chart to apply the method.

What to do with conflicting listings

  1. Prefer the printed label over a generic fit list.
  2. Ask the seller to confirm fit in writing.
  3. If two sellers disagree, stop and ask a specialist.
  4. Keep the reply with your order records.

Frequently asked questions

Is an SV code the same as a battery part number?

No. It identifies the machine variant. The battery part number is printed on the pack.

Can I match by photo alone?

No. Photos hide connector and label differences. Read the code.

What if the old pack is completely dead?

The label is still readable. Photograph it and send the code for a fit check.
