Frequently asked questions

Are all Dyson V-series batteries interchangeable?

No. V6, V7, V8, V10, V11, V12 and V15 use different shells, voltages or mounting systems. Match the part number on your old pack.

What is an SV code used for?

It identifies the machine variant on the Dyson plate. It is a useful cross-check, but the battery part number and voltage on the pack are decisive.

Where do I start if I only know the model name?

Open the compatibility chart, find the family, then compare the SV code examples with the plate on your machine.
